# Datathon Pós-Tech FIAP

## Projeto
Análise da base educacional da Associação Passos Mágicos utilizando técnicas de Analytics e Machine Learning.

## Objetivos

- Análise exploratória dos indicadores PEDE
- Avaliação da efetividade do programa
- Construção de modelo preditivo de risco
- Desenvolvimento de aplicação Streamlit

## Tecnologias

- Python
- Pandas
- Scikit-Learn
- Seaborn
- Streamlit
